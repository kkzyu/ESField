## 二、v6-D 架构设计

### 2.1 能量函数

```
E_guide = E_disp + E_protect

E_disp  = -B_j × M_reward(atom_i, HEW_j) × O(d_ij)
    O(d) = exp(-d² / (2 × sigma_occ²))

E_protect = w_wrong × E_wrong + w_clash × E_clash + w_overfill × E_overfill
```

其中：
- **B_j**: 每个 HEW 的环境奖励权重（hydrophobic=1.0, polar_unsatisfied=1.0, mixed=0.4, buried=0.3）
- **M_reward = softplus(compat) / softplus(1)**: 仅对兼容原子类型产生正向奖励
- **M_penalty = softplus(-compat) / softplus(1)**: 仅对不兼容原子类型产生惩罚

### 2.2 启发式兼容性矩阵 (4 环境 × 11 原子类型)

| Atom Type | Hydrophobic | Polar Unsatisfied | Mixed | Buried |
|-----------|-------------|-------------------|-------|--------|
| C_sp3 | **+1.0** | -0.3 | +0.3 | +0.3 |
| C_aromatic | **+1.0** | -0.3 | +0.3 | -0.5 |
| N_donor | -0.5 | **+1.0** | +0.3 | -1.0 |
| N_acceptor | -0.5 | **+1.0** | +0.3 | -1.0 |
| O_acceptor | -0.5 | **+1.0** | +0.3 | -1.0 |
| S | +0.3 | +0.3 | +0.2 | -0.3 |
| P | -0.3 | -0.3 | +0.1 | -0.5 |
| halogen | +0.3 | -0.3 | +0.2 | **+0.5** |
| charged | -1.0 | -1.0 | -0.5 | -1.0 |

**验证结果**: 矩阵三个关键性质全部通过：
- ✅ C_sp3 > charged 在 hydrophobic HEW
- ✅ O_acceptor > C_sp3 在 polar unsatisfied HEW  
- ✅ 两种类型在 mixed HEW 均获弱奖励

### 2.3 Actionable HEW 过滤

```python
# 过滤链（按顺序执行）
1. site_type == "high_energy_water"     # 仅 HEW
2. confidence >= min_confidence          # 默认 0.3
3. if filter_mixed: env != mixed         # 可选
   or confidence >= mixed_threshold      # 可选 0.7
4. top_k: score = conf × env_bonus      # 可选
```

## 四、已有实验数据分析

### 4.1 v5 Mechanism Test (5 口袋, 7 条件, ~80 mols/条件)

```
Condition         POSU      HEWU      d_HEW(A)  QED      SA     Validity
baseline (λ=0)   0.2104    0.1604    3.83      0.261    4.21   100%
v5 λ=0.1         0.2112    0.1613    3.85      0.249    4.19   100%
v5 λ=0.3         0.2112    0.1574    3.93      0.272    4.13   100%
v5 λ=0.5         0.2138    0.1630    3.84      0.277    4.17   100%

v5 random λ=0.5  0.2099    0.1579    3.87      0.259    4.17   100%
```

**v5 问题诊断**:
1. **POSU 改善微弱**: baseline→λ=1.0 仅 +2.7%
2. **Wrong-pocket 区分近乎为零**: gap = +0.001 ~ +0.013（噪声级别）
3. **QED 绝对水平极低**: baseline 0.261, λ=1.0 0.278（均低于 0.3 质量门槛）
4. **HEW 距离几乎不变**: d_HEW 从 3.83→3.81，仅近 0.02Å
5. **Hard pocket (1sle) 反而退化**: POSU 0.193→0.191

**Wrong-pocket 消融**:
```
Pocket  Correct  Wrong   Gap
3ohi    0.223    0.211   +0.013
2clh    0.281    0.275   +0.006
3mfw    0.184    0.181   +0.004
4bis    0.201    0.198   +0.003
1sle    0.191    0.192   -0.001  ← 反向!
```

**结论**: v5 的 MLP α/β 学到的是非特异性吸引力——对几乎所有原子类型都产生微弱的吸引，没有物理上有意义的 wrong-pocket 区分。

## 五、v6-D 能量景观演示结果

### 5.1 Demo 1: 1D 能量扫描

C_sp3 (兼容) 在 d=2.0Å 处受到 **0.263** 的吸引力（向 HEW 中心），而 O_acceptor (不兼容) 仅受到 **0.002** 的力。带电原子受到排斥力 (-0.072)，且力随距离增加而平滑衰减到零。

**对比 v5**: v5 对所有原子都产生类似强度的吸引力（因为 MLP 学到的是非特异性的），而 v6-D 的力严格依赖于化学类型。

### 5.2 Demo 2: 兼容性矩阵验证

三个关键验证全部通过，矩阵结构符合物理预期。

### 5.3 Demo 3: 保护项

- **Wrong-atom penalty**: charged 原子受到的惩罚力是 C_sp3 的 3.8×
- **Clash repulsion**: 1.0Å 近蛋白 → |grad|=0.97；4.0Å → 0.001

### 5.4 Demo 4: Overfill

4 个原子同占一个 HEW → penalty 是 1 个原子的 6.5×

### 5.5 Demo 5: 随机矩阵消融

正确矩阵力 = 0.263，随机矩阵力 = 0.089。差异 = 0.174，证明力来自物理规则而非随机结构。

### 5.6 Demo 6: 光滑性

20 个随机位置，全部有限梯度，无 NaN。二阶可微验证通过。

## 六、v6-D 超参数分析

### 6.1 sigma_occ 对吸引力的影响

```
sigma_occ  E_disp(d=2Å)  峰值吸引力  峰值距离
0.6        0.051          0.144      0.9Å    ← 太窄，仅近程有效
0.8        0.175          0.280      1.1Å
1.0        0.311          0.319      1.4Å
1.2        0.425          0.303      1.7Å    ← 推荐默认值
1.5        0.548          0.251      2.2Å
2.0        0.669          0.174      3.9Å    ← 太宽，特异性降低
```

**推荐**: sigma_occ=1.2 在吸引力和空间选择性之间达到平衡（峰值力在 1.7Å，2Å 处仍有 71% 的峰值力）。

### 6.2 wrong_atom_weight 平衡分析

```
w_wrong    C_sp3 (兼容)    O_acceptor       charged
0.0        +0.303 (吸引)    +0.117 (弱吸引)   +0.080 (弱吸引)
0.3        +0.279 (吸引)    +0.048 (微弱)     -0.011 (弱排斥)
0.5        +0.263 (吸引)    +0.002 (≈零)     -0.072 (排斥)    ← 推荐
0.7        +0.247 (吸引)    -0.043 (排斥)     -0.133 (排斥)
1.0        +0.223 (吸引)    -0.112 (排斥)     -0.224 (强排斥)
```

**推荐**: w_wrong=0.5 在"兼容原子被吸引"和"不兼容原子被惩罚"之间达到最佳平衡。O_acceptor 在 hydrophobic HEW 附近的受力≈0（不受奖励也不受惩罚），这是正确行为。

### 6.3 环境特异性力 (d=2.0Å, w_wrong=0.5)

```

  C_sp3: +0.263 ||||||||||    ← 强吸引
  C_aromatic: +0.263 ||||||||||
  halogen: +0.134 ||||||
  S: +0.134 ||||||
  O_acceptor: +0.002          ← 几乎为零
  charged: -0.072 ||||        ← 排斥

Polar Unsatisfied HEW:
  O_acceptor: +0.265 ||||||||||  ← 强吸引
  N_donor: +0.265 ||||||||||
  N_acceptor: +0.265 ||||||||||
  S: +0.136 ||||||
  C_sp3: +0.035 |               ← 微弱
  charged: -0.071 ||||           ← 排斥

  halogen: +0.008              ← 仅微弱奖励
```

## 七、关键发现总结

### 7.1 v5 的局限性（已量化证据）

| 问题 | 证据 | 严重程度 |
|------|------|----------|
| POSU 改善微弱 | baseline→λ=1.0 仅 +2.7% | 严重 |
| Wrong-pocket 无法区分 | gap +0.001~0.013，噪声级别 | 严重 |
| QED 极低 | baseline 0.26 (v5 test), 0.52 (6dvm) | 取决于口袋 |
| 非特异性吸引 | v5 对所有原子类型产生相似力 | 根本性问题 |
| 高 λ 饱和 | sum_norm λ=20 与 λ=1 无差异 | 方法上限 |

|------|------|

### 7.3 待 GPU 验证的假设

v6-D 在真实 DrugFlow 生成中的表现需要通过 5-pocket mechanism test 验证：

1. POSU/HEWU 改善应显著大于 v5 (+2.7%)

3. QED 不应低于 v5 baseline (<0.26)
