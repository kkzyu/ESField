## 一、背景与动机

### 1.1 v6‑D.2 的 NO‑GO 结论

v6‑D.2 实现了 capture‑to‑displacement 解析坐标引导：

```
E_guide = E_reward + w_wrong × E_wrong + w_clash × E_clash + w_overfill × E_overfill
E_reward = -Σ_j B_j × SoftMaxAgg_i( M_ij × [λ_cap·C(d) + λ_occ·O(d)] )
```

在 3 个 actionable pockets (2gni, 3mfw, 6o4x) 上的验证结果：

| Pocket | DirectOcc (Baseline) | DirectOcc (v6‑D.2) | 结论 |
|--------|---------------------|-------------------|------|
| 2gni | 0/60 | 2/60 | 极弱信号，random/wrong 可达到相近水平 |
| 6o4x | 0/51 | 0/48 | 无 occupancy，伴随 QED 下降 |
| 3mfw | 0/20 | 0/20 | 完全无响应 |

**根因分析**：Candidate HEW 利用需要 **拓扑层面的变化**（新增原子、改变取代基、调整原子类型），而不是仅靠坐标微调。coordinate‑only gradient 作用于错误的控制层级。

### 1.2 v7 的设计哲学

v7 从以下近期工作中汲取设计思路：

- **Metadiffusion**: inference‑time meta‑energy biasing — 在采样过程中注入可微能量函数的梯度
- **Lai et al.**: force field guidance on latent — 在 latent 层面施加物理约束
- **EBMol**: zero‑shot conditional generation by fixing atoms — 固定部分原子后条件生成
- **KPE + KTS**: Kinetic Path Energy + Kinetic Trajectory Shaping — 时变速度缩放控制探索-精修平衡

核心思想：

> **不修改 DrugFlow 权重，不重训练。将采样过程拆分为两阶段：先在 HEW 位点显式生长兼容片段（拓扑控制），再围绕锚点连接完整分子（几何精修）。**

## 三、核心模块详解

### 3.1 SiteCompatibilityEnergy

#### 能量定义

```
E(x_t) = - Σ_site Σ_atom [ compat(atom_type, site_env) × exp(-d_ij² / (2σ²)) ]
```

其中：
- `d_ij` = ‖x_i − site_center_j‖₂
- `compat ∈ [-1, +1]` 来自硬编码 4×11 兼容性矩阵
- `σ = 3.0 Å` — 软距离，提供较宽的 attraction funnel

#### 物理直觉

- **兼容原子靠近 site** → compat > 0, gauss > 0 → **负贡献**（降低能量/有利）
- **不兼容原子靠近 site** → compat < 0, gauss > 0 → **正贡献**（升高能量/不利）
- **任何原子远离 site** → gauss → 0 → **无贡献**

#### 兼容性矩阵

设计基于化学直觉，**不可学习**：

| Atom Type | Hydrophobic | Polar Unsatisfied | Mixed | Buried |
|-----------|:-----------:|:-----------------:|:-----:|:------:|
| C_sp3 | **+1.0** | −0.5 | +0.5 | +0.3 |
| C_aromatic | **+1.0** | −0.5 | +0.5 | −0.5 |
| N_donor | −0.5 | **+1.0** | +0.5 | −1.0 |
| N_acceptor | −0.5 | **+1.0** | +0.5 | −1.0 |
| O_acceptor | −0.5 | **+1.0** | +0.5 | −1.0 |
| S | +0.3 | +0.3 | +0.5 | −0.3 |
| P | −0.3 | −0.3 | +0.1 | −0.5 |
| halogen | **+1.0** | −0.5 | +0.5 | **+0.5** |
| charged | −1.0 | −1.0 | −0.5 | −1.0 |
| B | −0.3 | −0.3 | +0.1 | −0.3 |
| unknown | −0.5 | −0.5 | 0.0 | −0.5 |

**关键性质**（已在测试中验证）：
- ✅ C_sp3 ≫ charged 在 hydrophobic HEW
- ✅ O_acceptor ≫ C_sp3 在 polar unsatisfied HEW
- ✅ Mixed 环境对所有常见类型均有 ≥0 的中等兼容性
- ✅ 不兼容 pair 在近距离被惩罚（能量为正）

#### 梯度行为

对于兼容原子（compat > 0）：
```
E = -compat × exp(−d²/(2σ²))
∇E = compat × exp(−d²/(2σ²)) × x/σ²  → 远离 site (能量降低方向在 site 处)
Guidance: −λ∇E → 指向 site (正确方向)
```

对于不兼容原子（compat < 0）：
```
E = −compat × exp(−d²/(2σ²)) = |compat| × exp(−d²/(2σ²))  > 0
∇E = compat × exp(−d²/(2σ²)) × x/σ²  → 指向 site (负梯度)
Guidance: −λ∇E → 远离 site (正确方向)
```

### 3.2 KTSScheduler

#### 公式

```
        ⎧ 1 + α₀ × (1 − t/τ_split)              t < τ_split    (early boost)
η(t) =  ⎨
        ⎩ 1 − β₀ × (exp(k × (t − τ_split)) − 1)  t ≥ τ_split    (late damp)
```

其中 t ∈ [0, 1] (0 = noise, 1 = data)。

#### 参数

| 参数 | 默认值 | 物理含义 |
|------|--------|---------|
| α₀ | 0.01 | Early boost: η(0) = 1.01 — 促进早期拓扑探索 |
| β₀ | 0.01 | Late damping: 抑制末期过度约束 |
| τ_split | 0.6 | 转换点 (60% trajectory) |
| k | 3.0 | 指数阻尼刚度 |

#### 与 guidance 的集成

有效 guidance 强度：
```
λ_eff(t) = λ_base × η(t)
```

在采样中使用：
```
v_guided = η(t) × (v_pred − λ_base × ∇E)
```

### 3.3 TwoStageGenerator

#### Phase 1: Occupy (占位)

```python
for attempt in range(3):          # 最多 3 次重试
    fragments = model.sample(
        protein_data,
        n_samples=3,
        num_nodes=4,              # 小片段
        timesteps=50,
        guide_log_prob=phase1_guide  # 强 guidance + KTS boost
    )
    for mol in fragments:
        if check_occupancy(mol, sites, d_max=2.5, compat_min=0.5):
            anchors = extract_anchors(mol, strategy="best_per_site")
            return anchors  # → Phase 2
return None  # 所有尝试失败
```

**锚原子提取策略**：
- `best_per_site`（默认）：每个被占据的 site 取 score = compat × gauss 最高的原子
- `all_compatible`：所有符合 d ≤ 2.5Å 且 compat ≥ 0.5 的原子
- `nearest_compatible`：仅取距离最近的一个兼容原子

#### Phase 2: Connect (连接)

```python
guide = TwoStageGuideFn(
    site_energy=site_energy_p2,
    anchors=anchors,
    config=phase2_config
)
guide.set_anchor_indices([0, 1, ...], total_atoms=full_mol_size)

full_mols = model.sample(
    protein_data,
    n_samples=5,
    num_nodes=full_mol_size,
    timesteps=100,
    guide_log_prob=guide  # site energy + harmonic restraint + KTS damp
)
```

**复合引导能量**：
```
E_total = λ_late × E_site(x_t, all atoms) + k_restraint × Σ_{i∈anchors} ‖x_i − x_i^fixed‖²
```

### 3.4 TypeGuidanceBias

在采样中为原子类型 logits 添加兼容性偏置：

```
logits'_i = logits_i + β × Σ_j compat(site_env_j, type) × exp(−d_ij²/(2σ²))
```

- 靠近 hydrophobic site 的原子 → C_sp3, C_aromatic, halogen 的 logit 增加
- 靠近 polar unsatisfied site 的原子 → O_acceptor, N_donor 的 logit 增加
- 远离所有 site 的原子 → 偏置衰减到 0

**这是一个 soft bias**：不强制特定类型，只调整概率分布。

### 3.5 新评估指标

#### direct_occupancy_rate

```
occupancy_rate = |{mol : ∃ atom_i ∈ mol, site_j ∈ HEW s.t.
                   d_ij ≤ 2.5Å ∧ element(atom_i) ∈ compat_elements(site_env_j)}|
                 / |{all mols}|
```

#### best_compatible_distance

对每个 HEW site，计算所有生成的分子中最近的兼容原子距离：

```
best_d_j = min_{mol, atom_i∈mol, element(atom_i)∈compat(site_env_j)} d_ij
```

```python
def __call__(self, t_array, *, x, h, batch_mask, bonds=None, bond_types=None) -> torch.Tensor
```

DrugFlow 采样循环中的梯度注入（已由 `_patch_drugflow_lightning()` 完成）：
```python
with torch.enable_grad():
    ligand_tmp = ligand['x'].detach().requires_grad_(True)
    g = guide_log_prob(t_array, x=ligand_tmp, h=ligand['h'], ...)
    grad_x = torch.autograd.grad(g.sum(), ligand_tmp)[0]
delta_eps_lig = lam_t * grad_x
```

## 七、已知限制与后续工作

### 7.1 当前限制

1. **Phase 1 成功率未验证**: DrugFlow 在 4-atom 极小片段上的生成本身可能质量不足
2. **KTS 参数保守**: 默认 α₀=β₀=0.01 只产生 ~1% 调制，实际效果可能有限
3. **硬编码兼容性**: 矩阵基于化学直觉，未用实验数据校准；不区分 sp3/sp2 碳以外的精细类型
4. **仅坐标梯度**: 原子类型 logit 偏置 (TypeGuidanceBias) 已实现但未在 Phase 1 中默认启用
5. **无键约束**: anchor restraint 只约束坐标，不约束键连接性

### 7.2 后续改进

| 优先级 | 任务 | 说明 |
