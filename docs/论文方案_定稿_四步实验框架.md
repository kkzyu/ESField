## 核心叙事（定稿）

> Although recent 3D SBDD generators learn rich geometric regularities from protein-ligand complexes, **global plausibility does not guarantee local physicochemical opportunity utilization**. A generated ligand may be chemically valid, dockable, and geometrically plausible, yet fail to replace displaceable waters, preserve conserved waters, or fill hydrophobic cavities with compatible atoms. We therefore define **physical opportunity site utilization** as a missing evaluation and optimization dimension in 3D molecular generation. ESField operationalizes this concept by converting water- and cavity-derived site maps into an atom-site compatibility potential for inference-time guidance. To avoid mistaking forced site occupation for genuine improvement, we further introduce quality-constrained site metrics.

## Step 1: Opportunity-Blindness Diagnosis（诊断实验）

### 目标

证明：**传统指标（Vina, QED, SA, PoseBusters）好的分子，在局部机会位点利用上可能很差。**

### 实验设计

```
对 base generator (DrugFlow λ=0) 在 20+ pockets 上生成 20 molecules/pocket:

Step 1a: 传统指标筛选
  保留 validity=1, QED>median, SA<median, PoseBusters pass=1 的好分子

Step 1b: 计算 POSU（见指标定义）

Step 1c: 计算 SBR
  SBR = n(传统好但 POSU < median) / n(传统好)
```

### 主指标：SBR（Site-Blindness Rate）

```python
def compute_sbr(generated_molecules, site_maps, thresholds):
    """
    SBR = proportion of "good" molecules that are "site-blind"
    
    "good": validity=1, QED ≥ q_thresh, SA ≤ sa_thresh, 
            Vina ≥ v_thresh (top 30%), PoseBusters pass=1
    
    "site-blind": POSU < posu_thresh (below median of all molecules)
    """
    good = [mol for mol in molecules 
            if passes_quality_gate(mol, thresholds)]
    if len(good) == 0:
        return 0.0
    blind = [mol for mol in good 
             if compute_posu(mol, site_maps) < posu_threshold]
    return len(blind) / len(good)
```

- **Figure 1a**: Vina_score vs POSU scatter（每个点是一个分子，20 pockets × 20 samples）
- **Figure 1b**: SBR per pocket bar chart
- **Figure 1c**: "好的 Vina 分子" 和 "差的 Vina 分子" 的 site occupancy 可视化对比

### 预期

SBR > 30% — 即相当比例的传统好分子在 site utilization 上表现差。这证明 gap 存在。

### 做这个实验需要什么

- 不需要 GPU：用已有 baseline 生成结果即可
- 需要：20 pocket 的 site maps + baseline SDF
- 需要：Vina docking（CPU）
- 需要：实现 POSU 计算代码

## Step 2: Site Physical Meaningfulness（物理语义验证）

### 目标

证明：**site map 不是随便的空间吸引点。Site type 携带物理化学语义。**

### 实验设计

```
三个条件 × 5 representative pockets:
  Condition A: Correct site map（正确的 site type）
  Condition B: Shuffled site types（坐标不变，type 随机打乱）
  Condition C: Random site coordinates（在 pocket 内随机撒点，type 比例不变）

对每个条件跑 ESField guided generation（λ=1.0）
计算 POSU / HEWRU / SWDP
```

### 主指标：RSS（Random-Site Sensitivity）

```python
def compute_rss(posu_correct, posu_random, posu_shuffled):
    """
    RSS = min(POSU_correct - POSU_random, POSU_correct - POSU_shuffled)
    
    正值 → 正确 site map 确实更好
    接近 0 → site map 没有提供额外信息
    """
    return min(posu_correct - posu_random, posu_correct - posu_shuffled)
```

### 需要展示的图

- **Figure 2**: Three-condition bar chart（POSU per condition）

### 预期

RSS > 0 — correct > random ≈ shuffled。证明 site identity 重要。

### 做这个实验需要什么

- GPU：5 pockets × 3 conditions × 20 samples = 300 generations
- CPU：随机 site map 生成

## Step 3: ESField 改善 gap（方法验证）

### 目标

证明：**ESField guidance 能改善 POSU，且改善来自 site-type-specific 引导。**

### 实验设计

```
四条件:
  A: DrugFlow baseline (λ=0)         # baseline
  B: ESField λ=0.5                    # light guidance
  C: ESField λ=1.0                    # optimal guidance
  D: ESField with random site map     # negative control

20 test pockets × 20 samples each = 1600 generations
```

### 指标对比

```text
主指标:
  POSU: guided vs baseline（paired t-test）
  HEWRU: guided vs baseline
  SWDP: guided vs baseline ← 期望下降（或至少不显著上升）

辅助指标:
  SQD = 1 - corr(POSU, Vina)
  证明 POSU 和 Vina 相关但不等价

证据链:
  (a) POSU_guided > POSU_baseline (statistically)
  (b) HEWRU_guided > HEWRU_baseline (water displacement 改善)
  (c) SWDP_guided ≤ SWDP_baseline (没有破坏稳定水)
  (d) Random site → 改善消失 (证明 site identity 起作用)
```

## Step 4: Quality-Constrained Validation（质量约束验证）

### 目标

证明：**ESField 不是以牺牲分子质量为代价提高 POSU。**

### 实验设计

```text
计算 Q-POSU = POSU - QualityPenalty

QualityPenalty 构成:
  QED_drop = max(0, QED_baseline - QED_guided) / QED_baseline
  SA_worsen = max(0, SA_guided - SA_baseline) / SA_baseline  
  PB_fail = 1 - PoseBusters_pass_rate
  Vina_drop = max(0, Vina_baseline - Vina_guided) / |Vina_baseline|
  MW_inflation = max(0, MW_guided - MW_baseline) / MW_baseline
  validity_drop = max(0, validity_baseline - validity_guided)
  collapse_rate = proportion of duplicate molecules
  
QualityPenalty = mean of above
```

### λ sweep

```text
λ ∈ {0.1, 0.3, 0.5, 0.7, 1.0, 1.5, 2.0}

X-axis: POSU
Y-axis: QED / PoseBusters pass rate
Plot Pareto frontier

关键发现应该是:
  在 λ=1.0 以下: POSU 提升, QED 保持 (>0.4)
  在 λ=1.5 以上: POSU 继续提升, 但 QED 明显下降 / mode collapse
```

### 需要展示的图

- **Figure 4a**: λ sweep — POSU vs QED Pareto frontier
- **Figure 4b**: Q-POSU across λ values（最优 λ 对应最高 Q-POSU）
- **Figure 4c**: Per-condition quality breakdown table

### 预期

- 存在一个 λ 使得 POSU 显著改善而 quality 不显著下降
- λ > 1.5 后 quality 迅速恶化
- 论文推荐 λ=1.0 作为平衡点

## 指标体系（定稿）

### 主文指标（5 个）

| 指标 | 全称 | 含义 | 方向 |
|------|------|------|------|
| **POSU** | Physical Opportunity Site Utilization | 加权综合位点利用得分 | ↑ |
| **Q-POSU** | Quality-Constrained POSU | 考虑质量约束后的 POSU | ↑ |
| **SBR** | Site-Blindness Rate | 传统好分子中位点利用差的比例 | ↑（证明 gap 大） |
| **HEWRU** | High-Energy Water Replacement Utility | 高能水被兼容原子替换的效用 | ↑ |
| **SWDP** | Stable Water Disruption Penalty | 稳定水被不兼容原子占据的惩罚 | ↓ |

### 补充材料指标

| 指标 | 含义 |
|------|------|
| CASMR | Correct Atom-Site Matching Rate |
| SOR | Site Occupancy Rate |
| HCFU | Hydrophobic Cavity Filling Utility |
| SQD | Site-Quality Discordance (1 - corr(POSU, Vina)) |
| RSS | Random-Site Sensitivity |

### POSU 的正式定义

```python
def compute_posu(molecule, site_map):
    """
    POSU = Σ_j w_j × site_utility(j) / Σ_j w_j
    
    其中 site_utility(j) 根据 site type 定义：
    
    - HEW: max_i [ proximity(i,j) × I(atom_i is compatible with HEW) ]
      → 最近兼容原子越近，效用越高
    
    - SW: 1 - max_i [ proximity(i,j) × I(atom_i is INCOMPATIBLE with SW) ]
      → 没有不兼容原子靠近 = 满分
    
    - HC: max_i [ proximity(i,j) × hydrophobic_score(atom_i) ]
         - max_i [ proximity(i,j) × polar_penalty(atom_i) ]
      → 疏水原子靠近 + 极性原子远离 = 满分
    
    proximity(i,j) = exp(-d_ij² / (2 × σ_j²))
    compatible/incompatible: 硬编码规则（chemistry.py）
    
    w_j = site.confidence
    """
```

**关键性质**：POSU 只依赖几何距离和硬编码化学规则。不经过任何神经网络。完全可复现。

## 用 POSU 替代我之前方案中的 WABS

我之前在 v2 方案中提议的 WABS（Water-Aware Binding Score）现在应该被 POSU 取代。

原因：
- POSU 包含了 WABS 想要捕获的东西（水替换效用），但框架更完整
- POSU 覆盖三种 site type，而不是只关注水
- POSU 有 quality-constrained 版本（Q-POSU），直接回应审稿人的质量担忧
- "利用局部物理机会位点" 比 "水感知结合分数" 更准确地描述了我们实际在做什么

Vina 仍然在质量门控中使用，但不作为 primary metric。

11. Mode collapse rate < 5%
