# ESField 研究计划：能量位点引导的 3D 分子生成

更新时间：2026-05-11

## 一、我对这个 idea 的判断

这个 idea 可以发展成一个有明确方法边界、工程闭环和论文叙事的研究方向。它的核心研究问题不是“再训练一个更大的口袋条件分子生成模型”，而是：

> 给定蛋白质口袋和一个预训练的 3D 分子生成模型，能否把离线识别到的高能水、稳定水和疏水空腔等物理机会位点，转化为推断期可微势能场，从而把正确类型的配体原子引导到正确物理位点附近，在不显著破坏化学合法性和 3D 几何质量的前提下提高口袋适配性和结合相关指标？

输入是蛋白质口袋、离线 site map、预训练 3D pocket-conditioned generator；输出是受 site-aware energy guidance 修正后的候选配体。方法目标是补足现有 3D 分子生成常见缺陷：模型通常学习蛋白原子和配体原子的几何共现，但没有显式利用高能水置换、稳定水保护、疏水空腔填充这类局部物理机会。

这个方向可做，但不能把“势能网络”表述成真实物理自由能模型。第一版应明确：势能网络学习的是 atom-site compatibility potential，是用于生成引导的可学习局部势能，不等价于严格热力学自由能。论文中也不能声称“显著降低结合自由能”，除非后续有自由能计算或实验支撑；更稳妥的表述是“改善 docking / site matching / interaction quality 等结合相关代理指标”。

## 二、这个 idea 最需要补强的地方

1. 正样本不能只用“最近位点就是正样本”。真实配体原子靠近某个位点可能是合理相互作用，也可能只是空间邻近或位点检测误差。需要加入距离阈值、物理兼容先验、软标签和质量过滤。

2. 负样本不能只随机打乱原子类型。简单随机负样本太容易，网络可能只学到距离或常见元素频率。需要 hard negatives，例如距离近但类型不兼容的 pair、错误 docking pose、扰动构象、错误 site type、错误 pocket 的 site map。

3. 位点检测成本必须分层。WATsite / MD 类工具不适合一上来大规模跑全 CrossDocked。推荐把 WATsite 作为小规模精确验证，主实验先使用 fpocket + crystal water / hydration rule / 轻量水位点预测工具。

4. 推断期梯度引导需要稳定控制。过强的 `-grad E` 会把原子拉塌到少数位点，破坏键长、键角、价态和整体分子先验。必须设计 `lambda(t)`、梯度裁剪、距离截断、每位点容量限制和 late-stage guidance。

5. 评价指标必须证明“真的利用了位点”。只看 docking score 不够，因为 docking score 提升可能来自分子变大或疏水性增强。必须加入 Site Occupancy Rate、Correct Atom-Site Matching Rate、Stable Water Preservation Penalty、Hydrophobic Cavity Filling Score 等专属指标。

6. 与已有工作的区别需要最终检索确认。基于当前本地资料，可以把 ESField 定位为“inference-time site-specific learned potential guidance for pocket-conditioned 3D molecular generation”。但投稿前必须系统检索 energy-guided diffusion、pharmacophore-guided generation、water-aware SBDD、pocket hotspot guidance，避免创新点被已有工作覆盖。

## 三、最终推荐的技术路线

```text
Raw protein-ligand complexes
        ↓
Protein and ligand preprocessing
        ↓
Pocket extraction and split construction
        ↓
Offline energy-site detection
        ↓
Static site map construction
        ↓
Atom-site pair dataset construction
        ↓
Atom-site compatibility potential training
        ↓
Integration with pretrained 3D generator
        ↓
Inference-time gradient guidance
        ↓
Generated ligand evaluation
        ↓
Ablation, case study, failure analysis
```

推荐第一版采用 conservative MVP：

- base generator：优先选已有开源 pocket-conditioned 3D diffusion / flow model，先不重训主模型。
- dataset：PDBbind / CrossDocked2020 子集起步，后续扩到 CrossDocked2020。
- site detection：fpocket 负责口袋和疏水空腔；水位点先用 crystal water + 规则近似，WATsite 小规模验证。
- potential network：MLP-based atom-site energy model，先不做复杂 SE(3)-equivariant network。
- guidance：只引导坐标；原子类型只通过 expected energy 参与能量计算，第一版不直接改 logits。
- evaluation：docking + PoseBusters + molecule quality + site-specific metrics。

## 四、完整方法设计

### 4.1 研究对象定义

给定蛋白口袋 `P` 和预训练生成模型 `G_theta`，生成配体：

```text
M = (X, A, B)
X: N 个原子的 3D 坐标
A: 原子类型或原子类型分布
B: 化学键
```

离线 site map：

```text
S(P) = {s_j = (c_j, r_j, tau_j, q_j, u_j)}_{j=1..K}
c_j: 位点中心坐标
r_j: 位点有效半径
tau_j: 位点类型
q_j: 位点置信度或能量分数
u_j: 可选局部环境特征
```

第一版位点类型：

- `high_energy_water`：鼓励合适极性/疏水原子置换或占据附近机会。
- `stable_water`：默认保护，不鼓励不兼容原子占据；后续可扩展水桥。
- `hydrophobic_cavity`：鼓励疏水碳、芳香原子、卤素等填充。

### 4.2 势能网络边界

势能网络不负责发现位点。位点检测是离线预处理，势能网络只学习：

```text
E_phi(atom_i, site_j) -> scalar compatibility energy
```

低势能表示该原子类型、当前位置和该位点类型兼容；高势能表示不兼容或应远离。

### 4.3 总势能

对生成中间状态 `X_t` 和原子类型分布 `Pi_t`，定义：

```text
E_total(X_t, Pi_t, S)
  = sum_i sum_j w_ij sum_k Pi_t[i,k] E_phi(x_i, atom_type_k, site_j)
```

距离权重：

```text
w_ij = exp(-d_ij^2 / (2 sigma_j^2)) * I(d_ij < cutoff_j)
sigma_j = alpha * r_j
cutoff_j = max(4.0 Å, beta * r_j)
```

必须使用平滑截断或 soft weights，避免位点切换导致梯度不连续。

### 4.4 引导力

```text
F_site = - grad_X E_total
```

原子类型决定受力方向；受力方向不改变原子类型。若模型有原子类型分布，则使用 expected energy；若早期没有稳定类型分布，则只在中后期启用 guidance。

### 5.2 数据清洗规则

必须实现以下过滤：

- 去除缺失主链或严重缺失侧链的蛋白。
- 去除无效配体、断裂配体、含异常元素配体。
- 去除共价配体或反应型配体。
- 去除过大配体，例如重原子数 `> 80`。
- 去除过小配体，例如重原子数 `< 5`。

- 统一蛋白质 protonation 状态，记录工具和 pH 假设。

- 提取配体周围 `10 Å` 或 `12 Å` 口袋。
- 保留 crystal water 元数据，但训练主模型时是否使用水要由配置决定。
- 按 protein family / sequence similarity / pocket similarity 做 split，避免同源泄漏。

## 六、位点检测方案

### 6.1 高能水位点

优先方案：

- 小规模精确版本：WATsite 或同类 hydration thermodynamics 工具。
- 大规模轻量版本：crystal water + 局部环境规则 + 可选水位置预测模型。

高能水定义建议：

```text
water site energy score > high_energy_threshold
occupancy 不高或局部环境显示不稳定
距离口袋中心或参考配体 <= pocket_radius
距离蛋白重原子 > 1.8 Å
```

如果没有 WATsite 能量，可用近似规则：

- crystal water 周围氢键不足。
- 水位点处于疏水环境但被困在口袋内。
- 水位点被已知配体重原子置换频繁。
- 多复合物对齐后该水位置出现不稳定。

### 6.2 稳定水位点

稳定水默认代表不应被轻易置换的位置。识别规则：

- WATsite 显示低能或高 occupancy。
- crystal water 在同源结构或多构象中保守。
- 与蛋白形成 2 个以上稳定氢键。
- 位于桥接蛋白-配体相互作用的关键位置。

第一版处理：

- 对不兼容重原子产生高势能。
- 对可能形成水桥的供体/受体暂不强行吸引，只降低惩罚。
- 在论文中说明水桥建模是后续扩展，避免第一版目标过大。

### 6.3 疏水空腔

用 fpocket 提取 pocket alpha spheres，过滤得到疏水空腔：

- 聚类 alpha spheres 得到 cavity center。
- 使用 fpocket hydrophobicity / polarity score。
- 剔除距离蛋白重原子过近的点。
- 合并距离小于 `1.0 Å` 的重复位点。
- 每个 pocket 最多保留 `K_hydro = 10` 个疏水空腔。

兼容原子：

- 吸引：C_sp3、C_aromatic、halogen、部分 sulfur。
- 排斥：charged atom、强极性 O/N，除非局部环境有特殊相互作用。

### 6.4 位点质量控制

过滤规则：

- 位点必须在提取口袋内。
- 位点距离蛋白重原子不能过近，默认 `> 1.6 Å`。
- 位点距离参考配体或 pocket center 不能过远。
- 位点之间小于 `merge_distance = 1.0 Å` 时合并。
- 半径小于 `0.5 Å` 或大于 `3.5 Å` 的位点剔除。
- 每个 pocket 最多保留 `K = 20` 个位点。
- 每类位点数量极端不平衡时，在训练 pair 层面重采样。

## 七、atom-site pair 数据构建方案

### 7.1 正样本

正样本构造不能只靠最近邻。推荐主规则：

```text
positive if:
  d(atom, site_center) <= min(cutoff_type, alpha * site_radius + beta)
  and atom_type is not obviously incompatible with site_type
  and site confidence >= threshold
```

标签强度：

```text
label_strength = confidence(site) * exp(-d^2 / (2 sigma_site^2))
```

多匹配规则：

- 一个原子可匹配多个位点，但最多保留 top-2。
- 一个位点可匹配多个原子，但训练时加入 per-site cap，避免大配体贡献过多样本。
- 若最近位点距离过远，不构成正样本。

### 7.2 负样本

至少构造五类：

1. `atom_type_corruption`：固定位置和位点，替换为不兼容 atom type。
2. `site_type_corruption`：固定位置和中心，打乱 site type。
3. `pose_corruption`：用错误 docking pose 或随机扰动构象构造 pair。
4. `distance_corruption`：把原子平移到过近、过远或蛋白碰撞位置。
5. `hard_negative`：距离近但类型不兼容，例如带电原子靠近疏水空腔、疏水碳占据稳定水位点。

负样本比例：

```text
negative_ratio = 3
hard_negative_ratio = 0.4
random_negative_ratio = 0.4
pose_negative_ratio = 0.2
```

风险控制：

- 随机负样本过多会让任务太简单，需要 hard negative mining。
- docking decoy 可能本身不是严格负样本，应使用低评分或 clash 明显的 decoy。
- site type corruption 可能偶然生成合理组合，需要 label smoothing。

### 7.3 标签与 loss

主方案：margin energy loss。

```text
L_pair = y * softplus(E - E_pos_target)
       + (1-y) * softplus(E_neg_target - E)
```

推荐：

```text
E_pos_target = -1.0
E_neg_target = 1.0
```

备用方案：binary logistic energy loss。

```text
P(compatible) = sigmoid(-E)
L = - y log P - (1-y) log(1-P)
```

增强项：

- gradient penalty：限制 `||grad_x E||`。
- distance smoothness loss：相邻距离的 energy 不应剧烈跳变。
- class-balanced weight：解决 site type 不平衡。

## 八、势能网络设计

### 8.1 输入特征

最小输入：

```text
atom_type_embedding
site_type_embedding
relative_position_vector = (x_i - c_j) / r_j
distance_embedding = RBF(||x_i - c_j||)
site_radius
site_confidence
```

可选输入：

```text
local_pocket_composition
site_energy_score
water_occupancy
timestep_embedding
atom_partial_charge
atom_aromatic_flag
atom_hbond_donor_acceptor_flags
```

### 8.2 网络结构

第一版 MLP：

```text
Input features
  ↓
Linear( feature_dim, 256 ) + SiLU
  ↓
Residual MLP Block x 4
  ↓
LayerNorm
  ↓
Linear(256, 1)
  ↓
Scalar energy
```

输出约束：

- 用 `tanh` 或 energy clipping 限制初期输出范围，例如 `[-5, 5]`。
- 对远距离 pair 强制 energy 衰减到 0。
- 对 `grad_x E` 做 norm clipping，默认 `1.0`。

### 8.3 平移和旋转问题

使用相对坐标保证平移不变。旋转方面有两种选择：

- MVP 使用相对坐标向量 + 数据增强随机旋转，工程简单。
- 正式版本改为只用距离/RBF，或加入 SE(3)-invariant/equivariant 架构。

推荐第一版先用相对坐标 + random rotation augmentation；如果实验显示方向依赖不稳定，再切换到 invariant energy network。

### 8.4 总能量与容量限制

```text
E_total = sum_i sum_j cap_j w_ij E_ij
```

其中 `cap_j` 用于避免所有原子塌缩到一个位点：

```text
occupancy_j = sum_i I(d_ij < r_j)
cap_penalty = max(0, occupancy_j - max_atoms_per_site)^2
```

第一版可把容量限制放在 evaluation 和 failure analysis，若 collapse 明显，再加入 guidance penalty。

## 九、推断期引导算法

### 9.1 扩散模型

```python
for t in reversed(timesteps):
    x = x.detach().requires_grad_(True)

    base_score, atom_type_probs = model.score(x, protein, t)
    E = potential.total_energy(x, atom_type_probs, site_map)
    grad_E = torch.autograd.grad(E.sum(), x)[0]
    grad_E = clip_by_norm(grad_E, max_norm=cfg.guidance.grad_clip)

    lambda_t = lambda_schedule(t)
    guided_score = base_score - lambda_t * grad_E

    x = diffusion_update(x, guided_score, t)
```

关键实现点：

- `x` 只表示坐标部分，不直接对离散 atom type 求梯度。
- `atom_type_probs` 来自当前生成模型预测；若没有，则 late stage 使用已预测类型。
- 每步 `detach`，避免跨采样步保留计算图导致显存爆炸。
- 对 `grad_E` 做 clip，并记录梯度范数。

### 9.2 Flow Matching

```python
for t in ode_steps:
    x = x.detach().requires_grad_(True)

    base_v, atom_type_probs = model.velocity(x, protein, t)
    E = potential.total_energy(x, atom_type_probs, site_map)
    grad_E = torch.autograd.grad(E.sum(), x)[0]
    grad_E = clip_by_norm(grad_E, max_norm=cfg.guidance.grad_clip)

    lambda_t = lambda_schedule(t)
    guided_v = base_v - lambda_t * grad_E

    x = ode_solver_step(x, guided_v, t)
```

### 9.3 `lambda(t)` 推荐

不要从一开始就强引导。推荐：

```text
guidance_start = 0.35
guidance_end = 0.90
lambda_max = 0.05 - 0.2
schedule = cosine or sigmoid warmup
```

解释：

- early step 噪声大，site gradient 容易把未成形结构拉坏。
- middle step 结构形成，可引导关键原子占位。
- very late step 需要降低强度，避免破坏键长、键角和化学合法性。

### 9.4 类型不确定性

若有类型分布：

```text
E_expected_i_j = sum_k P(type_k | x_i, t) E_phi(x_i, type_k, site_j)
```

若没有稳定类型分布：

- 只在 late denoising steps 开启引导。
- 使用 top-k atom type 近似期望。
- 或直接输入连续 atom embedding 到势能网络，但这属于第二版。

## 十、实验设计

### 10.1 主实验

比较组：

1. Base generator。
2. Base generator + random site guidance。
3. Base generator + hand-crafted site potential。
4. Base generator + learned potential without water sites。
5. Base generator + learned potential guidance。
6. Base generator + docking post-optimization。
7. Full ESField。

主问题：

- ESField 是否提升 site matching？
- ESField 是否提升 docking / gnina / interaction 指标？
- ESField 是否保持 validity、PoseBusters、SA、QED 不显著下降？
- learned potential 是否优于手工规则？

### 10.2 消融实验

必须做：

- 去掉高能水。
- 去掉稳定水。
- 去掉疏水空腔。
- 只用一种位点。
- 不使用 hard negatives。
- 不使用 pose negatives。
- 不同 `lambda_max`。
- 不同 guidance start/end。
- 不同 site radius。
- 不同 distance cutoff。
- 不同 potential network 深度。
- 不同数据规模。

### 10.3 泛化实验

- unseen protein split。
- unseen pocket split。
- scaffold split。
- protein family split。
- 小规模 prospective-like case study。

### 10.4 失败分析

专门统计：

- 原子塌缩到少数位点。
- steric clash 增加。
- docking score 变好但 PoseBusters 失败。
- 生成分子过大导致 score 虚高。
- 位点检测错误导致错误引导。
- stable water 被错误占据。
- 高能水位点附近生成了不合理极性原子。
- 疏水空腔被带电原子占据。

### 11.3 蛋白-配体相互作用质量

- Vina score
- Vina minimized score
- gnina score
- hydrogen bond count
- hydrophobic contact count
- salt bridge / pi interaction count
- interaction recovery
- clash with protein

### 11.4 ESField 专属指标

Site Occupancy Rate：

```text
SOR = (# occupied valid sites) / (# target sites)
occupied if exists compatible atom within site radius
```

Correct Atom-Site Matching Rate：

```text
CASMR = (# occupied sites with compatible atom type) / (# occupied sites)
```

High-Energy Water Replacement Rate：

```text
HEWRR = (# high-energy water sites occupied by compatible ligand atoms) /
        (# high-energy water sites)
```

Stable Water Preservation Penalty：

```text
SWPP = mean_j I(stable_water_j occupied_by_incompatible_atom)
```

Hydrophobic Cavity Filling Score：

```text
HCFS = mean_j max_i exp(-d_ij^2 / 2 sigma_j^2) * I(atom_i is hydrophobic)
```

Energy Guidance Success Rate：

```text
EGSR = (# samples with lower final E_total and no PoseBusters failure) /
       (# generated samples)
```

## 十六、风险与备用方案

1. WATsite 成本过高。备用：小规模精确验证，大规模用 crystal water + 规则或轻量水位点预测。

2. 位点检测不稳定。备用：提高置信度阈值、合并位点、只保留 top-K、高质量 pocket 子集。

3. 正样本标签噪声大。备用：使用软标签、距离权重、只选高置信 pair。

4. 负样本太简单。备用：hard negative mining、decoy pose、距离匹配负样本。

5. 势能网络只学距离。备用：构造相同距离但不同类型的 negative，报告 controlled evaluation。

6. 引导过强导致分子崩塌。备用：late-stage guidance、降低 lambda、梯度裁剪、site capacity penalty。

7. docking score 改善但化学质量下降。备用：加入 PoseBusters gate、SA/QED 约束、报告 Pareto trade-off。

8. base generator 接口不开放。备用：选择更易改采样循环的开源模型，或先做 toy diffusion demo。

9. atom type uncertainty 难处理。备用：只在类型较稳定的后期使用 guidance，或使用 top-k expected energy。

10. 实验结果不显著。备用：收缩任务到 site matching proof-of-concept，作为 method prototype，而非声称全面提升亲和力。

11. 稳定水不一定总该排斥。备用：把 stable water 分成 protect site 和 water-bridge site，第一版只做 protect。

12. 静态 site map 忽略蛋白构象变化。备用：在 Discussion 中说明，后续结合 protein dynamics / ensemble site map。

13. 生成分子变大导致指标虚高。备用：匹配重原子数分布，报告 size-normalized docking score。

14. 数据泄漏导致效果虚高。备用：protein family split、pocket similarity split、scaffold split。

## 十七、最小可行版本 MVP

MVP 目标：证明“离线 site map + learned atom-site potential + inference-time coordinate guidance”是否能提高 site-specific metrics，而不是一开始证明真实结合自由能提升。

MVP 设置：

1. 选择 100-500 个 PDBbind/CrossDocked 复合物。
2. 用 fpocket 构建疏水空腔。
3. 用 crystal water + 简单规则构建高能/稳定水候选。
4. 构建 atom-site pair 数据集。
5. 训练 MLP potential。
6. 接入一个能修改采样循环的开源 3D generator。
7. 生成 guided / unguided 各 50-100 个 pocket 样本。
8. 比较 site matching、Vina、PoseBusters、validity。

MVP 成功标准：

MVP 最好达到以下 Go 标准，满足这些标准就可以认为方向值得继续扩大实验：

- potential validation：势能网络在验证集上能区分正样本和 hard negatives，AUROC 目标不低于 0.70，或 ranking accuracy 不低于 65%。同时，正样本平均势能应低于 hard negatives，不能只学到距离或元素频率。
- guidance stability：guided generation 无大规模 NaN、无明显原子塌缩。validity / connectivity / PoseBusters pass rate 相比 base flow matching 的下降不应超过 5 个百分点。
- site metric：至少一个核心 site-specific metric 相比 base flow matching 有稳定提升。优先看 Correct Atom-Site Matching Rate 和 Site Occupancy Rate，建议相对提升不低于 10%，或绝对提升不低于 5 个百分点。
- binding proxy：Vina / Vina-min median score 不应明显变差。MVP 阶段允许没有显著提升，但相对 base 的 median 下降最好不超过 0.2 kcal/mol；如果能提升 0.3 kcal/mol 以上，是强正信号。
- chemistry quality：必须报告 SA score。SA score、QED 和分子大小分布不能明显恶化，尤其不能靠生成更大、更疏水的分子换取 docking score。
- interpretability：至少给出 3 个可视化 case，分别覆盖高能水、稳定水保护和疏水空腔中的至少两类。case 需要展示 guided 相比 unguided 的原子--位点匹配变化。

No-Go 标准：

- 势能网络 AUROC 接近 0.5，说明 atom-site compatibility 没学出来。
- guided generation 导致 validity 或 PoseBusters pass rate 下降超过 10 个百分点。
- site-specific metrics 没有任何稳定提升。
- Vina / 几何质量明显恶化，且无法通过降低 guidance strength 修复。
