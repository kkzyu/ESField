## 三、发现与风险

### 3.1 Crystal water 缺失问题
CrossDocked 在构建时已移除蛋白结构中的 crystal water。这意味着 ESField 的 crystal water site detection 在所有 CrossDocked 受体上都会返回 0 个 site。

**解决方案**：
- 方案 A：从原始 PDB 文件中提取 water 坐标，再映射回 CrossDocked 受体
- 方案 B：使用 water 预测工具（如 WatSite、3D-RISM）在 CrossDocked 受体上预测水位点
- 方案 C：仅依赖 fpocket 的疏水空腔检测 + 其他非水 site 类型

方案 C 对 MVP 最可行，但会限制 ESField 的价值主张（water sites 是核心卖点）。

### 3.2 fpocket 安装问题
fpocket 不在 pip 仓库中，conda 源有 SSL 问题，apt 不包含。需要从源码编译或配置 conda 镜像源。

### 3.3 GPU 不可用
当前机器无 GPU 驱动或 GPU 硬件。租卡后需要重新配置 CUDA 环境，但 PyTorch 代码不需要修改。
