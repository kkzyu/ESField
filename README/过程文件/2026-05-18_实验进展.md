## 2026-05-18 晚间更新：POSU 指标修复与验证

### POSU v1 的问题

`max_i` 算子导致单个"幸运"原子可以为 site 刷分。坐标随机打散的分子 POSU 反而上升。

### 修复方案

1. `max_i` → `top-2 mean` (HEWU/HCFU)：稀释单原子效应
2. 加入分子完整性因子：检查重原子间是否有接触（cutoff=3.0Å），无接触→POSU 接近零

### 验证实验 (6dvm pocket)

**1. 晶体配体测试**

| | POSU | 完整性 |
|------|------|--------|
| 共晶配体 | **0.343** | 0.83 |
| 生成分子 (均值) | 0.322 | 0.78 |

✅ 共晶配体 > 生成分子

**2. 扰动测试**

| 操作 | POSU | Δ |
|------|------|-----|
| 原始 | 0.343 | — |
| 平移 +2Å | 0.335 | -2.3% |
| C→O 替换 | 0.329 | -4.1% |
| 坐标打散 | 0.059 | -83% |

✅ 所有扰动均降低 POSU

**3. SQD**

SQD=0.51, Spearman ρ=0.49 (p=0.33)

✅ POSU 与 Vina 不冗余
