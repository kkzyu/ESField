## 背景

v6-D.2 coordinate-only guidance 在 actionable-pocket validation 中被判定为 NO-GO。根因：候选 HEW 位点利用需要拓扑层面的变化（新增原子、改变取代基、调整原子类型），仅靠坐标微调无法稳定实现。

v7 从根本上改变策略：将采样拆分为两个阶段，在 HEW 位点处显式生长兼容片段（拓扑控制），再围绕锚点连接完整分子（几何精修）。

## 核心设计决策

1. **不训练**：兼容性矩阵完全硬编码（化学规则），不学习任何参数
2. **坐标梯度 + 类型偏置分离**：梯度仅作用于 x_t；类型由 TypeGuidanceBias 软偏置
3. **KTS 时变缩放**：early boost (α₀) 促进拓扑探索，late damp (β₀) 用于几何精修
4. **Phase 1 小片段 + Phase 2 完整分子**：显式控制拓扑变化 vs 几何精修
5. **兼容现有接口**：引导函数完全兼容 DrugFlow 的 guide_log_prob 签名
