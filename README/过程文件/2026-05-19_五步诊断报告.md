## 逐 Check 详情

### Check 1: Native Ligand POSU Discrimination

| 指标 | 值 |
|------|-----|
| PASS (Δ>0.01 both) | 6/20 |
| Mean Δ(random) | +0.020 ± 0.009 |
| Mean Δ(shuffled) | -0.005 ± 0.016 |
| HEWU Δ(correct-random) | **+0.116** ± 0.021 ✅ |
| SW_p Δ(correct-random) | **-0.086** ± 0.014 ❌ (方向相反) |
| HCFU Δ(correct-random) | +0.041 ± 0.012 ⚠️ |

**发现**:Native ligand 的 HEWU 在 correct site map 上确实更高(+0.116)。但 SW_p 在 correct site map 上更低(-0.086)，因为真实配体会替代稳定水——这是真实 binding 行为，但 POSU 把它当作错误惩罚。两项抵消导致 POSU 不敏感。

**根因**: POSU 的 SW 子指标惩罚了真实配体的正常 binding 行为。SW 不应该只用"不能破坏稳定水"来衡量——应该区分:
- 破坏且不补偿 (bad)
- 破坏但通过直接极性作用补偿 (acceptable)
- 保持并通过水桥利用 (good)

### Check 2: Per-Component RSS (Generated Molecules)

| 子指标 | Δ(correct-random) | p | 方向 |
|--------|-------------------|---|------|
| HEWU | **-0.020** | 0.034* | ❌ 反了 |
| SW_pres | +0.026 | 0.074 n.s. | ⚠️ 弱改善 |
| HCFU | -0.001 | 0.882 n.s. | — 无差异 |
| POSU | +0.003 | 0.417 n.s. | — 无差异 |

**关键发现**: HEWU_correct < HEWU_random (p=0.034)。用正确 site map 引导产生的分子，其 HEW 位点利用反而比随机 site map 更差。

**根因**: ESField guidance 把所有原子拉向所有 site（Check 4 证明）。多个 site 的竞争性梯度使分子扭曲，兼容原子最终离 HEW site 更远。

### Check 3: Potential AUC Decomposition

| 验证 | AUC | 解读 |
|------|-----|------|
| Ordinary | 0.939 | 看似很好 |
| **Distance-matched** | **0.701** | 控制距离后大幅下降 |
| Type-shuffled | 0.844 (Δ=-0.095) | site type 有微弱贡献 |
| No-distance | 0.778 (Δ=-0.161) | 去掉距离仍 > 随机 |

| 距离区间 | Distance-matched AUC |
|----------|---------------------|
| 1.5-2.5Å | 0.959 |
| **2.5-3.5Å** | **0.657** |
| 3.5-5.0Å | 0.715 |

**发现**: Potential 学到了 type 信息(no-distance AUC=0.778)，但在 guidance 操作的关键距离范围(2.5-3.5Å)表现最差(AUC=0.66)。距离信号比 type 信号强约 6-10 倍。

### Check 4: Force Direction Matrix

**关键发现**: 几乎**所有** atom-site 对都是吸引的。Correct compatible pairs 是对的(吸引)，但 **incompatible pairs 也被吸引**。

| | HEW | SW | HC |
|---|-----|-----|-----|
| C_sp3 | ✅ ← | ⚠️ ← (错误吸引) | ✅ ← |
| C_aromatic | ✅ ← | ⚠️ ← | ✅ ← |
| N_donor | ✅ ← | ✅ ← | ⚠️ ← |
| O_acceptor | ✅ ← | ✅ ← | ⚠️ ← |
| S | ✅ ← | ⚠️ ← | ✅ ← |
| halogen | ✅ ← | ⚠️ ← | ✅ ← |

Force magnitude 在 2-3Å 范围:兼容对约 -0.1 到 -3.9，不兼容对约 -0.01 到 -2.3。

**根因**: Potential 没有学到"排斥 incompatible pairs"。它是一个**非特异性吸引场**。所有原子被所有 site 拉。

### Check 5: Nearest Compatible Atom Distance

| Site Type | Baseline | λ=1.0 | Δ |
|-----------|----------|-------|---|
| HEW compatible | 3.81Å | 3.92Å | **+0.11 ↑** |
| SW compatible | 5.46Å | 5.44Å | -0.02 ≈ |
| HC compatible | 7.17Å | 7.28Å | **+0.10 ↑** |

**关键发现**: ESField guidance 后，HEW 和 HC 的**兼容原子距离反而增加**。虽然单对 force 是吸引的(Check 4)，但真实生成中多个 site 的竞争性梯度导致分子扭曲，兼容原子被推到更远的位置。

SW incompatible 距离增加是有益的——不兼容原子被推离稳定水。这解释了为什么 SW preservation 改善。

## 完整根因链

```
Potential 训练时负样本设计有问题
  → AUC 被距离信号虚高 (0.94)
  → Distance-matched AUC 只有 0.70
        ↓
Potential 学到了"距离近=兼容"而不是"type 匹配"
  → 所有 atom 被所有 site 吸引 (非特异性吸引场)
  → 不能区分 compatible vs incompatible pairs
        ↓
Generation 时 guidance 产生竞争性梯度
  → 每个原子被 10-20 个 site 同时拉
  → 分子构象扭曲 (QED 下降)
  → 兼容原子最终离 HEW/HC site 更远
        ↓
HEWU 下降 (p=0.034)
SW preservation 消极改善 (原子远离所有 site)
HCFU 不变
  → POSU 无明显改善 (p=0.072)
  → RSS ≈ 0
```

## POSU 的独立问题

除了 potential 的问题，POSU 本身也有设计缺陷:

1. **SW 指标惩罚真实 binding 行为**: 真实配体会替代稳定水，但 POSU 把任何 SW 附近的不兼容原子都当惩罚
2. **HEW compatible 规则过宽**: 几乎所有原子都兼容 HEW → 指标对 random site 也能得分
3. **SW 和 HEW 在 composite 中方向相反**: 两者互相抵消 → total POSU 不敏感

POSU 需要改成:
- SW: 区分"破坏性替代"(bad)和"补偿性替代"(acceptable)
- HEW: 收紧 compatible 规则
- 引入 per-site-type 加权而非简单平均

## 修复优先级

### P0: 修 POSU (先于一切)
1. SW 拆成 SWDP(penalty) + SWBR(bridge reward)
2. HEW compatible 按 HEW 局部环境分类收紧
3. Random site 对照加强(增加 wrong-pocket site map)
4. POSU 用 native ligand 作为 calibration

### P1: 修 Potential 训练数据
1. 增加 same-distance wrong-type negatives (逼模型学 type)
2. 增加 type-shuffled negatives
3. 在 1-4Å 范围正样本上设置 negative energy target (宽吸引盆地)

### P2: 修 Potential 结构
1. Per-site-type prediction heads
2. 手工势能形状 + MLP compatibility 系数: E(a,s,d) = α(a,s) × U(d)
3. 用 distance-matched AUC 作为验证指标(非 ordinary AUC)

### P3: 修 Guidance
1. Per-site-type gradient weighting
2. Guidance schedule 优化
3. Gradient competition resolution

# 附录 A：POSU-v2.1 实现与校准（同日完成）

## A.1 架构改动（vs v1）

| 组件 | v1 | v2.1 |
|------|-----|------|
| SW 指标 | 单一 SWDP penalty | **SWP + SWBR + SWCR + SWDP** 四项分解 |
| HEW compatible | 所有 atom 几乎都兼容 | **按局部环境分类**（hydrophobic / polar_unsatisfied / mixed / buried） |
| SW disruption 判据 | proximity > 0.01 | **硬距离阈值 d < 2.5Å** |
| Mixed HEW | weight 1.0 | **降权 0.6** |
| Composite 权重 | HEW=1.0, SW=1.0, HC=1.0 | **HEW=1.2, SW=0.6, HC=0.8** |

## A.2 HEW 环境分类规则

| 环境 | 条件 | 兼容原子 | weight |
|------|------|---------|--------|
| hydrophobic | hbond≤1 & hydrophobic≥4 | C_sp3, C_aromatic, halogen, S | 1.0 |
| polar_unsatisfied | hbond≤1 & hydrophobic≤2 | O_acceptor, N_donor, N_acceptor | 1.0 |
| mixed | 其余 | 以上全部 + O/N donors | 0.6 |
| buried | nearest_protein < 2.5Å | C_sp3, halogen | 1.0 |

## A.3 SW 四项分解

- **SWP** (preservation): 无不兼容原子在 2.5Å 内 → 满分
- **SWBR** (bridge reward): 极性原子在理想桥接距离（3.2Å）→ 水桥利用
- **SWCR** (compensated): 极性原子直接占据水位点 → 补偿性替代
- **SWDP** (destructive): 不兼容原子破坏水且无补偿 → 惩罚

总 SW 分数逻辑:
- 无破坏 → 1.0
- 有破坏但有补偿 → max(0, 1.0 - 0.5×SWDP + 0.3×SWCR)
- 有破坏无补偿 → max(0, 1.0 - SWDP - 0.1×SWBR)

## A.4 校准结果

| 对照 | v1 | v2.1 |
|------|-----|------|
| correct > random PASS | 6/20 | **12/20** |
| correct > wrong-pocket PASS | N/A | **12/20** |
| Mean ΔPOSU(random) | +0.020 | **+0.034** |
| SW anti-correlation | -0.086 | **-0.038** |
| HEWU signal | +0.116 | +0.103 |

**结论**: POSU-v2.1 通过率从 6/20 翻倍至 12/20，SW 反向问题改善 2.3 倍。未达 14/20 目标但可作 MVP 指标冻结。Shuffled-at-same-positions 对照过严，已被 wrong-pocket 和 random-coordinate 替代为主对照。

# 附录 B：Potential v5 实现与离线验证（同日完成）

## B.1 架构改动（vs v4）

**v4**: E = MLP(atom, site, rel_pos, distance, RBF, radius, confidence)
→ 纯 MLP 学习能量，结果学到"距离近 = 兼容"

**v5**: E(a,s,d) = -α(a,s)·A(d) + β(a,s)·R(d)
- A(d) = exp(-(d-3.0)²/(2×1.5²)) × smooth_cutoff(d, start=4.5, end=6.0)  — 手工吸引井
- R(d) = exp(-d/0.5)  — 短程硬排斥
- α, β = softplus(MLP(...))  — MLP 只学兼容性系数

**参数**: 111,970 params, hidden_dim=128, num_layers=3
